IMAGES
======

Drop your photos into the folder that matches the part of the site they belong to,
then type the path into that section's editing file. Example:

    photo: "images/boutique/linen-shirt.jpg"

Folders:
  images/home/         hero halves, home page photos
  images/boutique/     boutique hero, category circles, products, collections
  images/automotive/   automotive hero, categories, products, promos
  images/fireworks/    fireworks photos
  images/services/     workshop photo
  images/about/        storefront / team photo

You never have to use files: leaving photo: "" lets you drag an image straight
onto the placeholder in the page, and the page remembers it.
